# First retirement bonus

The first player to complete the Welcome Letter / cabin-lodge retirement card earns $1,000 in game money. The server awards it once, includes it in cash/final scoring, records it in the game journal, and shows a banner to all players. Later retirees receive no first-place bonus. The award is saved with the room and survives refreshes and restarts.

For a room where someone already retired before this update, the game does not award a later player a false first-place prize. Start a new room for a full playthrough with the bonus.

Upload engine.mjs, test.mjs and the public folder to GitHub, then redeploy Render and refresh every device. Keep the persistent disk.
